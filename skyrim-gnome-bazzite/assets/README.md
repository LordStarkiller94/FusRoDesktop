# assets/

Nothing in this folder is generated by the installer or by an AI tool —
it's hand/tool-authored art and theme CSS. Each subfolder has a `SPEC.md`
describing exactly what the installer expects to find there (file names,
formats, sizes). Until a given subfolder is populated, `install.sh` simply
skips that component and tells the user why — the installer never fails
because assets are missing.

| Folder | Component | Spec |
|---|---|---|
| `icons/Skyrim-Icons/` | XDG icon theme | [icons/SPEC.md](icons/SPEC.md) |
| `cursors/Skyrim-Cursors/` | XDG cursor theme | [cursors/SPEC.md](cursors/SPEC.md) |
| `gtk-theme/Skyrim-Gtk/` | GTK3 theme | [gtk-theme/SPEC.md](gtk-theme/SPEC.md) |
| `shell-theme/Skyrim-Shell/` | GNOME Shell theme | [shell-theme/SPEC.md](shell-theme/SPEC.md) |
| `wallpapers/` | Desktop + lock screen images | [wallpapers/SPEC.md](wallpapers/SPEC.md) |
| `plymouth/skyrim/`, `plymouth/grub/` | Boot splash + GRUB menu | [plymouth/SPEC.md](plymouth/SPEC.md) |

If you're forking this repo for a different game theme: this is the only
directory (plus `theme.manifest.yaml`) you need to replace. Everything in
`lib/` reads paths from the manifest and doesn't care what game it is.
